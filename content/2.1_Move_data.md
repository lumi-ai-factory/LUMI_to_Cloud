# Moving data to Google Cloud

To move your datasets and model weights from LUMI to a Google Cloud Storage bucket, you first need to configure the Google Cloud CLI% and authenticate.

## Google Cloud CLI Setup

To safely install and run the Google Cloud CLI% on LUMI, you should operate inside a container% using a Python virtual environment%. 

1. **Navigate to your working directory**
   
   Before you begin, navigate to the directory where you want to install the Google Cloud CLI. This can be either your `$HOME`% directory or any of your project folders like `/scratch/<project_id>` or `/project/<project_id>`.

2. **Enter the container shell**
   
   First, clear your loaded environment modules, load the necessary bindings, and enter a container% that already includes most required dependencies (like `lumi-multitorch` created and maintained by LAIFs%).
   
   ```bash
   module purge
   module use /appl/local/laifs/modules
   module load lumi-aif-singularity-bindings
   singularity shell /appl/local/laifs/containers/lumi-multitorch-latest.sif
   ```

3. **Set up a virtual environment**
   
   Create and activate a virtual environment%. Using the `--system-site-packages` flag ensures your environment inherits the pre-existing dependencies from the container%.
   
   ```bash
   python3 -m venv venv --system-site-packages
   source venv/bin/activate
   ```

4. **Download and install Google Cloud CLI**
   
   Download the latest CLI package, extract it, and run the installation script. Extracting the archive may take a minute or two.
   
   > [!warning]
   > During installation, you will be asked:
   >
   > "Modify profile to update your $PATH and enable shell command completion?"
   >
   > Type **n (NO)**. 
   
   ```bash
   curl -O https://dl.google.com/dl/cloudsdk/channels/rapid/downloads/google-cloud-cli-linux-x86_64.tar.gz
   tar -xf google-cloud-cli-linux-x86_64.tar.gz
   ./google-cloud-sdk/install.sh
   ```

## Transferring data with `gcloud`

Once the Google Cloud CLI% is installed, you are ready to move your datasets and model weights.

1. **Authenticate**
   
   Whenever you need to use `gcloud`% in the future, you must temporarily add it to your path by manually sourcing% the configuration file before running commands.
   
   Add `gcloud` to your path temporarily (adjust the path if installed elsewhere):
   
   ```bash
   source ~/google-cloud-sdk/path.bash.inc
   ```
   
   Authenticate your Google Cloud account (follow the steps on screen):
   
   ```bash
   gcloud init
   ```

2. **Transfer your files**
   
   You can now copy files and directories using the `gcloud storage cp` command.
   
   ```bash
   # Example Download (from Google Cloud to LUMI):
   gcloud storage cp gs://YOUR_BUCKET_NAME/FILE_NAME .
   
   # Example Upload (from LUMI to Google Cloud):
   gcloud storage cp FILE_NAME gs://YOUR_BUCKET_NAME/
   ```
