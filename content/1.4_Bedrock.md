# Hosting an LLM on AWS Bedrock

AWS Bedrock Custom Model Import allows user to import your own customized version of certain Foundational models into the Amazon Bedrock ecosystem.  By doing this, you can leverage the existing Amazon Bedrocks Features and Amazon Bedrocks converse API and access the model on a serverless manner.

Currently there are certain things you need to know about: 
- Amazon Bedrocks Consoles, where you will import and access the model, is not part of the trial use credits. 
- The Custom model import is only supported in the following regions: 
    - `eu-central-1`
    - `us-east-1`
    - `us-east-2`
    - `us-west-2`
- The models you import must be in one of the following architectures: 
    - Mistral
    - Mixtral
    - Flan
    - Llama 2, Llama 3, Llama 3.1, Llama 3.3 and Mllama
    - GPTBigCode
    - Qwen2, Qwen2.5, Qwen2-VL, Qwen2.5-VL, Qwen3
    - GPT-OSS 
- The size of imported model weights must be less than 100GB for multimodal models and 200GB for text models. 
- Maximum positional embeddings or the maximum context length should be less than 128k. 

For more technical information about the supported importing format or model precision, you can visit [AWS Documentation for using Custom Model Import](https://docs.aws.amazon.com/bedrock/latest/userguide/model-customization-import-model.html). 

## How to import the Custom model into Amazon Bedrock 
AWS does have official guide on how to do the importation. The process is simple as everything can be done on the AWS Bedrock Consoles. 
- Go into the Amazon Bedrock Consoles and choose **Foundational models** and then **Imported models**
- Click **Import Model** to configure the process. 
- You can import from either Amazon S3 or a SageMaker Model ARN object.
- Configure:
    - the Job name
    - your AWS Key Management Service (AWS KMS) key for encryption 
    - Service access role 
- After the Import Model job is complete, check the model and the model ARN to use later. 
- You can test the imported model using on-demand feature in Text playground. 
- Now you can access the custom imported model through API as well to invoke model for inference. 

_For more information regarding the latest documentations of Custom model import, please visit [AWS official documentation](https://docs.aws.amazon.com/bedrock/latest/userguide/import-pre-trained-model.html)._
